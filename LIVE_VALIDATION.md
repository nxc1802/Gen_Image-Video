# Factory v4 Live Validation & Release Gate

Factory v4 must not be labelled production-certified from contract simulation alone. A release may set a model's `validation_status: live_verified` only after the applicable checks below pass against real infrastructure and real model weights.

## 1. Environment prerequisites

Production must set `ENVIRONMENT=production`, `FACTORY_API_KEY`, PostgreSQL, Redis, S3/MinIO credentials, all reserved ngrok domains, and trusted asset/media host allowlists. Raw ComfyUI endpoints require the ngrok vault secret referenced by `infrastructure/ngrok/traffic-policy-raw.yml`.

Expected persistent infrastructure:

```text
Control Plane -> PostgreSQL + Redis + S3/MinIO
Text/VLM/Decision/Embedding/Rerank -> native vLLM
Speech ASR -> native vLLM
Speech TTS -> native vLLM-Omni
Image/Video -> native ComfyUI + Factory queue-worker sidecar
Music -> native ACE-Step 1.5 + Factory queue-worker sidecar
Enhancement -> explicitly configured real model workers
```

## 2. Startup/fail-closed gate

Verify production refuses to start when any required durable dependency is missing:

- empty/missing `FACTORY_API_KEY`;
- PostgreSQL unavailable;
- Redis unavailable;
- S3 unavailable or credentials invalid;
- default MinIO credentials;
- required native model backend absent.

No production path may silently switch to SQLite, in-memory queue, local artifacts, pseudo vectors, lexical ranking, generated placeholder media or synthetic speech/music.

## 3. Network/security gate

For every public domain:

- invalid/missing authorization is rejected;
- CORS accepts only configured origins;
- admin/worker APIs enforce their role boundary;
- WebSocket credentials do not appear in URLs;
- SSRF probes against loopback, RFC1918, link-local, metadata endpoints, IPv6 local addresses and DNS rebinding are blocked;
- redirects cannot bypass the media/asset host allowlist;
- oversized and invalid-MIME asset requests are rejected;
- raw ComfyUI domains are protected by the ngrok raw-API policy.

Restart each worker/session repeatedly and verify its reserved ngrok domain does not change.

## 4. Durable job/queue gate

Submit at least 100 jobs concurrently across mixed modalities. Validate:

- every accepted job has exactly one durable job record;
- idempotency keys do not duplicate jobs;
- priorities are respected;
- worker leases are exclusive and atomic;
- heartbeat extends active leases;
- worker death causes DeadJobReaper recovery/retry;
- cancellation reaches the native backend;
- retry count/max retry rules are enforced;
- no job is reported SUCCEEDED without real artifact/model output;
- Postgres/Redis restart does not silently lose accepted jobs.

## 5. Streaming gate

Validate real—not simulated—streams:

- Text/VLM token SSE;
- Decision response path;
- ASR realtime/chunk streaming;
- TTS audio streaming where the selected vLLM-Omni model/backend supports it;
- ComfyUI image/video WebSocket progress;
- Factory SSE/WS job events;
- reconnect/resume behavior and terminal events after reconnect.

## 6. Model inference gate

Run golden inputs against the actual target hardware.

### Text
Validate Chat Completions, Responses API, structured output, tool calls, streaming and context limits.

### VLM
Validate image/video inputs only from allowed media hosts, document QA, grounding and streaming.

### Decision
Validate native predicate/choice/score output from `/v1/decisions`. Calibration claims require labelled evaluation data; never derive calibration metrics heuristically.

### Embedding/Rerank
Verify vector dimensions/norms/semantic retrieval and real reranker ordering. Backend outage must return 503 and never substitute pseudo vectors or BM25.

### Speech
Verify real Qwen3-ASR transcription, native Qwen3-TTS audio, voice cloning with reference audio + text, and any timestamp/alignment capability only when a real aligner backend is configured.

### Image
Execute every capability marked true in `manifests/models/qwen-image-2.1.yaml` and verify the exact ComfyUI output file is uploaded to Factory Storage.

### Video
Execute every capability marked true for Wan and MiniMax. Verify unsupported model/task pairs are rejected before queue admission and never cross-route to another family.

### Music
Verify ACE-Step `/release_task -> /query_result -> /v1/audio`, then verify the Factory sidecar uploads the actual generated bytes to durable storage. Source-audio tasks remain disabled until their native staging path is implemented and validated.

### Enhancement
Keep manifest capabilities false until real Real-ESRGAN/RIFE/audio-enhancement workers are connected and return persisted artifact metadata.

## 7. Artifact integrity gate

For every generated media type:

- S3 SigV4 upload succeeds through the public presigned hostname;
- SHA-256 stored in the job matches downloaded bytes;
- MIME/type/size are correct;
- presigned URLs expire as configured;
- a missing ComfyUI/backend output causes FAILED/RETRYING, never a placeholder artifact.

## 8. GPU/admission gate

On Kaggle dual T4, validate exclusive admission. Eligible services listed on a GPU are not assumed resident simultaneously. Test model start/stop, OOM recovery, VRAM reclamation and worker restart for each profile.

## 9. Studio gate

Build the Next.js application and test:

- manifests load dynamically;
- unsupported capabilities cannot be submitted;
- API key is entered/stored by the user and is not compiled into the public bundle;
- Job Dashboard cancel/retry works;
- SSE/WS inspector reconnects;
- code generation matches the selected API contract;
- raw native APIs are clearly distinguished from Factory Job APIs.

## 10. Certification rule

Only after the relevant live gates pass:

1. record hardware, driver/CUDA/framework/model versions;
2. store benchmark/golden artifacts and hashes;
3. record the test run/commit SHA;
4. update only the validated models to `validation_status: live_verified`;
5. do not convert a partial capability matrix to full unless every required capability is implemented and tested.

Contract tests, mock transports and source review remain necessary CI checks, but they are not substitutes for this live certification.
